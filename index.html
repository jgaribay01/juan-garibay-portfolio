05 — How these numbers were made

Measured from git history, the file system and Claude Code session transcripts, all read on 2026-08-18. Line counts use one method across all seven builds: authored source only, excluding dependencies, build output, third-party libraries and generated files. Counting another way moves these figures by up to three times, so the method travels with the number. Several systems are still in active development, so these are a snapshot rather than a ceiling — the Rutero test count rose from 749 to 1,186 in the five days before this reading.
